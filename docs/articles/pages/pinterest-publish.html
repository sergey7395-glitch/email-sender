Pinterest: инструмент для пинов

Выберите товар, получите название, описание, замещающий текст, ссылку и список досок. Нажмите кнопки копирования и вставьте в Pinterest. Опубликованные пины можно отмечать, отметки хранятся в этом браузере.

1. Доски (девять штук)

Создайте по одной: «+» → «Создать доску», название и описание копируйте кнопками, галочку «частная» не ставьте. Пустые доски выглядят плохо: когда создадите, сразу сохраните туда по 5–6 пинов. Доска 1 главная (туда публикуем все пины), 2, 8, 9 общие по теме, 3–4 по площадкам, 5–7 по категориям товара. Каждый пин попадает в четыре доски: главную, одну общую, одну площадочную и одну категорийную.

2. Пин: выберите товар

Или впишите свой товар. Название так, как его ищут: «кофеварка», «электробритва».

3. Готовые тексты

Публикация: «Создать пин», загрузить оригинал карточки из галереи, вставить тексты, включить тумблер «Отметить как изменённый с помощью ИИ», выбрать главную доску и опубликовать. Потом на самом пине нажмите «Сохранить» и добавьте его в другие доски из списка выше. Не больше 3–5 пинов в день.
