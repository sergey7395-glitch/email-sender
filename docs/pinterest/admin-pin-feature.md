# Идея для разработчика: кнопка «Подготовить пин» в админке

Цель: выбрал карточку в галерее, нажал одну кнопку и получил всё для пина, не копируя ничего вручную.

## Минимальная версия (без API Pinterest)
1. В Галерее у карточки (главной картинки серии) кнопка **«Подготовить пин»**.
2. Открывается окно: товар (из названия заказа, можно править), «что показывают» (по умолчанию из шаблона категории), вариант названия (3 шаблона из `docs/pinterest/pins.csv`).
3. Генерируются: название пина, описание, замещающий текст, ссылка с `utm_source=pinterest&utm_medium=pin&utm_campaign=cards&utm_content=<slug>`, список досок (общая, «Инфографика/Wildberries/Ozon» по шаблону названия, категорийная).
4. Кнопки «Копировать» у каждого поля и **«Скачать картинку для Pinterest»**: оригинал, дополненный фоном до пропорций 2:3 (например, 1000×1500), чтобы убрать предупреждение Pinterest о соотношении сторон.
5. Журнал: какие карточки уже стали пинами (дата, доска, ссылка на пин), чтобы не повторять.

## Расширение
- Публикация пина через Pinterest API (создание пина с картинкой, ссылкой, описанием, доской, расписание). Нужно проверить, доступно ли получение доступа к API для аккаунта из РФ, и пройти проверку приложения. До проверки это не обещаем.
- Тексты через модель (вместо фиксированных шаблонов) с проверкой: без цифр и характеристик, которых нет на карточке; без чужих брендов в названии.

## Правила
- Только карточки, разрешённые к показу (оферта п. 6.3, клиент не отказался); не публиковать исходные фото клиентов и игровые/чужие бренды.
- Не больше 3–5 пинов в день на аккаунт.
- Метки ссылок как в шаблоне, чтобы статистика Метрики по Pinterest не ломалась.
