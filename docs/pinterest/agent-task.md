# Задание агенту с доступом к браузеру: публикация пинов Cardroom в Pinterest

Контекст: у владельца бизнес-аккаунт Pinterest «Cardroom» (сайт absolutecard.ru подтверждён). Нужно опубликовать пины с готовыми карточками. Пин 1 («Овощерезка») уже опубликован.

## Что есть
- `docs/pinterest/pins.csv` (разделитель `;`, кодировка UTF-8): для каждого пина название, описание, замещающий текст, ссылка, доска, имя файла картинки.
- Папка `pins` у владельца с картинками. Имена файлов как в колонке «файл (положить в папку pins)». Картинки подобрал владелец (только свои и разрешённые по оферте п. 6.3 карточки; без исходных фото клиентов, e-mail, цен и внутренних данных).

## Как публиковать (по одному пину)
1. Зайти в уже залогиненный Pinterest, открыть создание пина.
2. Загрузить картинку из папки `pins`.
3. Вставить название, описание, замещающий текст («Добавить замещающий текст») и целевую ссылку из CSV без изменений.
4. Включить тумблер «Отметить как изменённый с помощью ИИ». Галочку «человек, созданный ИИ» ставить только если на картинке есть сгенерированный человек.
5. Выбрать доску «Карточки товара для маркетплейсов» (она уже создана).
6. Публиковать «сейчас» только первые 3 пина в день, остальные ставить через «Опубликовать позже», по 3–5 пинов в день, начиная с завтрашней даты.
7. После каждого пина записывать в колонку «статус» в CSV: `опубликован` или `запланирован на ДАТА`.

## Правила
- Не вводить и не просить пароли. Работать только в уже открытой сессии владельца.
- «Рекламировать пин», тег Pinterest, подтверждение сайта, смена профиля: не трогать.
- Если Pinterest показывает капчу, предупреждение или ограничение, остановиться и сообщить владельцу.
- Ничего не менять в текстах и ссылках. Первые два пина показать владельцу до продолжения.
